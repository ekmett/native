# Base-two exponential and logarithm

`math::exp2` and `math::log2` preserve binary32 scalar, SIMD, array and wide
shapes. Their kernels operate directly in base two. The selected coefficients
are generated by the accompanying Sollya scripts under the repository license;
no external coefficient table is imported.

## Reductions and contracts

`exp2` uses `n = round_even(x)`, exact reduced `r = x - n`, six Horner
multiply-adds approximating `2^r`, and exp's existing exponent reconstruction.
The constant coefficient is exactly one, making all normal integer powers from
-126 through 127 exact. Inputs at or above 127.5 return positive infinity.
`exp2<true>` selects zero below -126. Default subnormal results retain exp's
backend-specific behavior: ARM/AVX2 single-factor reconstruction returns zero
when n <= -127, AVX-512 uses masked scaling, and Wasm uses two factors.
NaNs propagate without a payload promise. Neither variant changes FP controls.

`log2` separates the binary exponent and mantissa, folding at binary32 sqrt(2)
(word `0x3fb504f3`). For `r = m - 1`, the exact interval is
`[-0x1.2bec34p-2, 0x1.a82790p-2]`. A degree-nine Horner polynomial approximates
`log2(1+r)/r`; one final multiply-add combines `r*h + exponent`, for ten stages
in total. Normal powers of two return their exact integer exponents, including
positive zero for `log2(1)`. Zeros and signed subnormals give negative infinity;
negative normals and NaNs give canonical quiet NaN; positive infinity is kept.

Native x86 and ARM use fused stages. Baseline Wasm uses separately rounded
multiply/add, even when the consumer enables relaxed SIMD. These approximations
are qualified in nearest-even mode, without promises about libm exception flags
or correct rounding for every input.

## Reproduce the fits

With Sollya 8.0:

```sh
sollya tests/transcendentals/base2/exp2.sollya
sollya tests/transcendentals/base2/log2.sollya
```

Both use 256-bit working precision and binary32 coefficient formats. Exp2 fixes
the constant to one and minimizes relative error on `[-0.5,0.5]`. Log2 minimizes
absolute error for its divided logarithm on the reduced interval above.
`dirtyinfnorm` output is an uncertified estimate for the unrounded polynomial,
not an error bound on its floating-point evaluation.

## Numerical qualification

The larger exp2 search tested 4,375,032 entries covering a dense residual grid,
full-range grid, seeded raw encodings and neighborhoods of half-integer reduction
boundaries. MPFR160 references gave at most one representable-float step for
actual NEON wide6, an explicit fused graph, and a separately rounded graph model.
Actual NEON output matched the fused graph across that bank.

The log2 search tested 3,028,243 unique normal inputs against MPFR256, including
near-one and mantissa-fold neighborhoods, exponent transitions, a stride-eight
mantissa scan, and 500,000 seeded broad-domain encodings. Actual scalar/NEON wide6
and the separate graph model reached at most two representable-float steps.
The maintained regression includes the observed worst-input neighborhoods.
These searches are sampled evidence, not exhaustive binary32 accuracy proofs.

The maintained `promoted_base2.cc` fixture checks both functions, public aliases,
all supported native float lane counts, packs of 1/2/6 registers, empty inputs,
constexpr/runtime agreement, exact powers, exceptional values, and normal-domain
accuracy against a two-ULP budget. Subnormal exp2 results have classification
checks without an accuracy budget. Native execution checks gradual and flush FP
modes; Wasm executes in Node and Wasmtime. Enable `NATIVE_TEST_MPFR` for MPFR256
references; the fallback reference uses double libm.

```sh
cmake --build build/core --target native_test_promoted_base2_header native_test_promoted_base2_import
ctest --test-dir build/core -R native.promoted_base2 --output-on-failure
```

## Code generation

`codegen.cc` exposes one-, two- and six-register wrappers. Compile it at `-O3`
with C++26, `-fms-extensions`, `-ffp-contract=off`, `-Isrc`, and the intended
target's flags. Add `-S` to inspect assembly. The inspected Clang 23.1.1 wrappers
contain no calls, runtime branches or scalarized floating-point lane operations.
Polynomial FMA counts are 6/12/36 for exp2 and 10/20/60 for log2.
Math and native adapter routes emit identical assembly in these fixtures.

NEON and AVX-512 six-register wrappers have no arithmetic-body spills. AVX2
six-register wrappers spill: exp2 has 16 vector stores and 16 reloads, log2 has
10 each. One- and two-register AVX2 wrappers avoid vector spills. These are
static Clang 23.1.1 Apple-ABI counts, including folded reloads but excluding ABI
register saves. They do not establish throughput or a universally optimal pack
size. AVX-512 log2 at two registers has one predicate spill/reload.
